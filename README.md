# 使用方法

## 启动与停止

打开 Docker Desktop，在项目根目录执行相应命令。

| 操作 | 命令 |
| --- | --- |
| 首次启动 | `docker compose up -d --build` |
| 日常启动 | `docker compose up -d` |
| 停止 | `docker compose down` |

启动后打开 [本机工作台](http://127.0.0.1:5173)。

## 对话

登录后直接在首页输入问题。点「试试跟我说」旁边的例子，可以先填进输入框。想从头聊时点「新对话」。

点侧栏底部的账号可以设置用户名，首页会用这个名字打招呼。最多 10 个汉字或 20 个英文字母，混用时一个汉字占两位。

点左侧的会话标题继续聊。打开「历史对话」后，可以输入标题按回车搜索，也能按助手和时间筛选。会话旁的「⋯」菜单可重命名或删除对话。

## 写稿

1. 从「专家库」选择功能专家。可以按名称或用途搜索，点星号收藏的角色会显示在「我的专家」。点卡片，在一个输入框填写要求或粘贴素材，再点「开始生成」。短视频编导、公众号编辑和选题策划都可以从空白开始。
2. 在稿件区点「编辑」修改文字，也可以从「自己写」直接进入编辑器。选中一段后可润色、缩写或换语气，确认后应用到选区。点「保存版本」写入新版。
3. 从「历史对话」打开稿件，在版本下拉框选择要看的版本，再点「导出 Markdown」。

## 人物项目

1. 打开「人物故事与定位」，点「新建人物档案」。可以说一句你在做什么或想拍什么，也可以直接新建。
2. 在「分步创作」点「帮我想选题」或「帮我想定位」，AI 会直接开始。已有故事、定位或选题可从对应卡片的「⋯」菜单粘贴。
3. 有访谈或样稿时，到「资料与版本」粘贴或上传 DOCX、TXT、MD、文字版 PDF。更新原文时点「新增版本」。
4. 在选题下选一条「按题写口播」。生成期间可以离开页面，回来在「生成记录」打开结果。
5. 改稿时点「保存版本」。要查看旧稿用过的资料，先切换版本，再点正文引用或「这个版本的来源」。定位更新后，在对应口播稿旁点「重做这篇」。
6. 要移除某份人物档案，先选中它，再点「删除档案」。档案对应的稿件也会从历史对话里移除。

## 视频字幕

1. 打开「给视频加字幕」，上传 H.264 编码的 MP4，有声音时使用 AAC 编码。
2. 选择「按录音识别」「逐字稿对齐」或「导入 SRT」。逐字稿也可以从稿件编辑器点「给这版稿配字幕」带入。
3. 打开已完成的任务，点字幕行跳到相应时间。修改文字或起止时间后，点「保存时间轴」。
4. 点「下载 SRT」，或点「导出带字幕的 MP4」。视频导出后回到同一任务下载成片。

## 充值申请

启用充值申请时，将收款码保存为 `config/recharge-qr.png`。

1. 打开「充值申请」，选择预设金额或输入实际支付金额。
2. 使用页面中的二维码付款，上传 PNG 或 JPG 付款截图，按需填写备注。
3. 点「提交申请」，保存页面显示的申请编号。管理员核对截图后手动添加积分，入账状态和余额可在充值页查看。

## 管理后台

在工作台登录页点 [管理员登录](http://127.0.0.1:5173/admin/login)，登录后直接进入管理后台，侧栏显示「管理员北极熊」。新部署时先注册账号，再由部署者将该账号的 `account.role` 设为 `ADMIN`。

1. 在「充值记录」打开付款截图，核对后点「入账」并填写积分，也可以标记「未通过」并填写原因。
2. 在「用户管理」搜索、新增或编辑账号。可手动添加积分、查看积分记录、停用账号或恢复登录。
3. 在「AI 提供商配置」填写 OpenAI 兼容的 API 地址、模型名称和 API 密钥。点「测试连接和速度」查看耗时，点「保存配置」后生效。

部署时可在本机 `config/ai.properties` 中添加 `spring.ai.openai.api-key=你的密钥`，为默认的 DeepSeek 上游提供密钥。
