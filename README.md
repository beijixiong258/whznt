# 使用方法

平台功能和技术路线请参阅[产品文档](./产品文档.md)。

## 下载 Release 镜像运行

从 [GitHub Releases](https://github.com/beijixiong258/whznt/releases) 下载 `whznt-0.1.0-linux-amd64.tar`，打开 Docker Desktop 的 Linux 容器模式，在 PowerShell 中执行以下命令。

```powershell
docker load -i .\whznt-0.1.0-linux-amd64.tar
docker run -d --name whznt --stop-timeout 30 -p 127.0.0.1:5173:80 `
  -v whznt-release-db:/var/lib/postgresql/data `
  -v whznt-release-files:/var/lib/whznt `
  whznt:0.1.0
```

容器健康状态显示 `healthy` 后，打开 [本机工作台](http://127.0.0.1:5173)。日常用 `docker stop whznt` 和 `docker start whznt` 停止和启动。重新创建容器时继续挂载上述两个卷，即可保留数据库、资料和视频。

### 首次启动时创建管理员

在本机的 `config/release-admin.properties` 中填写管理员凭据。

```properties
whznt.bootstrap-admin.phone=你的11位大陆手机号
whznt.bootstrap-admin.password=你的6到20字符密码
```

执行上面的 `docker run` 时，在镜像名之前加入以下挂载参数，从当前目录读取配置文件。

```powershell
--mount "type=bind,source=$((Get-Item .\config\release-admin.properties).FullName),target=/run/whznt/config/release-admin.properties,readonly" `
```

容器就绪后，在 [管理员登录页](http://127.0.0.1:5173/admin/login) 使用上述凭据登录，显示名称为「管理员北极熊」。再次启动时使用数据库中已保存的管理员账号。

也可以在工作台注册账号后手动开通管理员。执行 `docker exec -it whznt gosu postgres psql -U whznt -d whznt` 进入数据库，将下面的手机号替换为刚注册的手机号后执行。

```sql
UPDATE account SET role = 'ADMIN' WHERE phone = '已注册的手机号';
```

登录后台后，在「AI 提供商配置」填写文本模型的 API 密钥。

从源码构建同款镜像时，在项目根目录运行 `docker buildx bake -f docker-bake.hcl --load release`。

## 从源码启动与停止

打开 Docker Desktop，在项目根目录执行相应命令。

| 操作 | 命令 |
| --- | --- |
| 首次启动 | `docker compose up -d --build` |
| 日常启动 | `docker compose up -d` |
| 停止 | `docker compose down` |

启动后打开 [本机工作台](http://127.0.0.1:5173)。

## 对话

登录后直接在首页输入问题，也可从「专家库」点「通用 AI」进入对话。点「试试跟我说」旁边的例子，可以先填进输入框。回复下方有「复制回复」按钮。想从头聊时点「新对话」。

点侧栏底部的账号可以设置用户名，首页会用这个名字打招呼。最多 20 个字符。

在左侧「历史对话」点会话标题，就能回到聊天框继续聊。可以按标题和时间查找，会话旁的「⋯」菜单可重命名或永久删除对话。

## 写稿

1. 从「专家库」的 19 位功能专家中选一位。可以按名称或用途搜索，点星号收藏的角色会显示在「我的专家」。进入后可填写要求、粘贴素材或留空，点「开始生成」。想换专家，点标题上方的「返回专家库」。
2. 生成完成后，正文上方可点「复制正文」「改标题」或「编辑正文」。点「保存修改」写入新版本，也可以「下载稿件」或「给这版稿配字幕」。
3. 想让 AI 改稿，就在正文下方「跟专家说怎么改」输入一句话，例如「开头写得更口语一点」。发送后，AI 按当前稿件修改并保存新版本。
4. 下次从左侧「我的稿件」按标题、创作助手或时间找回。稿件有多个版本时可以切换查看，查看旧版时点「编辑最新版」可回到当前版本修改。

## 人物项目

1. 打开「人物故事与定位」，点「新建人物档案」。可以说一句你在做什么或想拍什么，也可以直接新建。
2. 在「分步创作」点「帮我想选题」或「帮我想定位」，AI 会直接开始。已有故事、定位或选题可从对应卡片的「⋯」菜单粘贴。
3. 在「资料与版本」可以打开本档案的「已保存成果」，也可以粘贴或上传 DOCX、TXT、MD、文字版 PDF 资料。更新原文时点「新增版本」。
4. 等生成完成，正文会在档案页打开。可以直接「复制正文」，或点「编辑正文」再「保存修改」。生成时离开了页面，回来可在「生成记录」点「查看结果」。
5. 在定位结果点「用当前定位想选题」。选题生成后，点「选一条写口播」，再对喜欢的题目点「按题写口播」。点标题上方的返回按钮可回到打开成果的地方。
6. 选中档案后点「删除档案」，确认后会永久删除档案、资料和稿件。

## 视频字幕

1. 打开「给视频加字幕」，上传不超过 512 MB 的 H.264 编码 MP4，有音轨时使用 AAC 编码。
2. 视频有音轨时可选「按录音识别」或「逐字稿对齐」。逐字稿可以粘贴，也可从专家稿件或人物口播稿点「给这版稿配字幕」带入。已有字幕文件时选「导入 SRT」，上传不超过 1 MB 的 SRT，也支持无音轨的视频。
3. 打开已完成的任务，点字幕行跳到相应时间。修改文字或起止时间后，点「保存时间轴」。
4. 点「下载 SRT」，或点「导出带字幕的 MP4」。视频导出后回到同一任务下载成片。

## 充值申请

1. 打开「充值申请」，选择 200、500 或 1,000 元，也可点「自定义金额」填写 1 至 1,000,000 元的整数金额。
2. 按页面显示的金额扫码付款，上传一张不超过 10 MB 的 PNG 或 JPG 付款截图，可填写备注。收款码显示后才可以提交申请。
3. 点「提交充值申请」，成功后页面会显示申请编号。管理员核对截图后手动入账。
4. 点页面右上角「申请记录」查看付款截图、处理状态和留言。积分余额显示在充值页顶部。

### 重复截图和被拒后重提

- **提示截图重复**。同一账号的截图已用于「待处理」或「已入账」的申请时，系统会拦截新申请，并提示原单的状态和编号。可到「申请记录」查原单。另一笔付款请上传那笔付款的截图。
- **申请被拒绝**。在「申请记录」找到「已拒绝」的申请，从「留言」查看原因。回到充值表单，按原因更正金额、截图或备注，再点「提交充值申请」。如果原截图符合要求，且此前只用于已拒绝的申请，可以重新上传原图。重提成功后会收到新申请编号，状态为「待处理」。
- **同一次提交重试**。系统已收到申请时，因网络问题重试同一次提交会返回原申请编号。

## 管理后台

在工作台登录页点 [管理员登录](http://127.0.0.1:5173/admin/login)，登录后直接进入管理后台，侧栏显示「管理员北极熊」。新部署时先注册账号，再由部署者将该账号的 `account.role` 设为 `ADMIN`。

1. 在「充值管理」右上角点「收款二维码」，选一张不超过 10 MB 的 PNG 或 JPG，再点「保存收款码」。保存后新图会替换当前收款码。
2. 在「充值管理」的「待处理」打开付款截图，核对后点绿色「入账」填写正整数积分，或点红色「拒绝」填写原因。在「留言」列查看用户备注和处理说明。
3. 在「用户管理」搜索、新增或编辑账号，直接在列表点「停用」或「启用」。点「删除」并确认，会永久删除普通账号及其业务记录。点「添加积分」可手动入账，点「积分记录」查看每笔入账明细。
4. 在「AI 提供商配置」填写 OpenAI 兼容的 API 地址、模型名称和 API 密钥。点「测试连接和速度」查看耗时，点「保存配置」后生效。

部署时可在本机 `config/ai.properties` 中添加 `spring.ai.openai.api-key=你的密钥`，为默认的 DeepSeek 上游提供密钥。
